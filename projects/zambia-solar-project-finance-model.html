Anonymised project finance case

58.5 MWdc / 50 MWac Zambia solar IPP financial model and lender review

A development-stage solar project required a finance case that connected energy yield, PPA terms, EPC cost, operating assumptions and lender protections to debt capacity and investor returns.

Request similar supportView services
Case classificationAnonymised development-stage assignment

Client and counterparty names are omitted. Public figures are limited to information suitable for a portfolio summary.

Asset58.5 MWdc / 50 MWac solar PV
Project usesApprox. US$59.4m
PPA case25 years
Year 1 energyApprox. 123.5 GWh P90
Debt frameworkUp to 75% debt cap
Model outputs11.9% project IRR / 15.0% equity IRR

01

Situation

The project was being advanced through a ring-fenced project company with commercial and industrial offtake, grid connection and wheeling workstreams still requiring final documentation and approvals.

02

Mandate

Review and strengthen the lender-style project finance model, test bankability, translate model outputs into financing questions and support the finance section of the project feasibility work.

03

Analysis completed

  • Reviewed the revenue build from PPA tariff, escalation, P90 generation, degradation and availability assumptions.
  • Tested EPC cost, development cost, operating cost, working capital, tax and reserve-account treatment.
  • Reviewed debt sizing, interest, repayment sculpting, CFADS, DSCR, LLCR, cash waterfall and distribution constraints.
  • Tested tariff, yield, delay, CAPEX and operating-cost downside cases.
  • Mapped lender questions around payment security, termination payments, reserve funding, grid interruption and curtailment.
  • Separated completed model logic from contractual and technical workstreams that remained conditions to financial close.

04

Decision value

The work clarified which assumptions supported the base-case returns, which risks reduced debt capacity and which commercial protections had to be resolved before lenders could rely on the model.

Public case-study boundary

The project and client are anonymised. Figures shown are rounded portfolio-level metrics. They do not represent a financing commitment, final lender approval or a claim that all project agreements were executed.

Deliverables

  • Lender-style Excel model review
  • Assumption and issue register
  • Debt sizing and cover-ratio analysis
  • Downside sensitivity pack
  • Bankability questions for project agreements
  • Finance input to feasibility documentation
